Riftbound TCG Tools

Price Update

Match one or more TCGCSV exports against a Shopify product export to generate a price update CSV. Quantities are never touched.

Set Code Map

Map each TCGCSV group name to the Shopify set code. Only mapped sets will be processed — others will warn.

Promo Set Code Map

Auto-detects which set a promo belongs to from its card number total.

Rune Promo Suffix Map

Rune promos use a letter suffix (e.g. R01b, R01c). Map suffix letter to set code.

Currency Conversion
Applied to all TCGCSV prices before rounding. Set to 1 to disable conversion.
